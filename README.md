## /work

### Backend Architecture
Microservices that handle real throughput. FastAPI, Quart, and NestJS wired together with JWT auth chains, distributed queues, and CQRS patterns. PostgreSQL for relational data, MongoDB for documents, Redis for when Postgres gets tired.

### Security Engineering
Not compliance. Actual offense. I build tools for fingerprinting, evasion, fuzzing, and forensic analysis. OWASP/OSSTMM/MITRE are reference points — the real work happens in the terminal at 2 AM.

### ML for Detection
Models in PyTorch trained on traffic patterns and behavioral signals. Inference pipelines wired directly into production backends. Use case: catching what signature-based rules miss.

### Hardware
ESP8266/ESP32 sensors for WiFi-based signal analysis. Passive keypress detection through RSSI/CSI fluctuation patterns — no camera, no touch driver, no kernel module. Just RF physics and clustering algorithms.
